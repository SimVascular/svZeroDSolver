enum class ActivationSignalType
strong

Type of signal an ActivationFunction produces.

Used to catch mismatched activation_function/active_stress pairings: an ActiveStress model declares the signal type it needs via ActiveStress::required_signal_type, and ChamberSphere::setup_dofs checks it against the chamber's ActivationFunction::signal_type.
