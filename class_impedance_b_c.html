Detailed Description

Structured-tree impedance boundary condition with periodic memory.

Imposes the outlet pressure as a discrete convolution of the impedance kernel with one cardiac cycle of flow history, following the structured-tree outflow condition of [6].

Governing equations

The entries are discrete-time convolution weights. The term depends on the current flow, so it enters the system matrix directly; the history terms ( ) are evaluated from accepted timesteps only, held in a fixed-size ring buffer spanning one cardiac cycle.

The ring buffer is zero-initialized, so the history terms are omitted entirely until one full cycle has been accepted, after which they switch on at full magnitude. This reproduces the reference implementation, which gates the same sum on t > Period, and makes the pressure discontinuous at the start of the second cycle. The first cycle is therefore not a meaningful solution and should be discarded.

Local contributions

Parameters

  • z: Time-domain impedance kernel. Its length must equal one cardiac cycle in time steps (see the timing requirements below).
  • Pd: Distal/reference pressure. Optional, defaults to 0.0.
  • convolution_mode: exact (default) or truncated. In truncated mode only the first num_kernel_terms kernel entries are used, which costs per accepted timestep instead of one full cycle.
  • num_kernel_terms: Number of kernel terms. Required when convolution_mode is truncated, ignored otherwise.

Usage in json configuration file

"boundary_conditions": [
    {
        "bc_name": "OUT",
        "bc_type": "IMPEDANCE",
        "bc_values": {
            "Pd": 0.0,
            "z": [ ... ],
            "convolution_mode": "exact",
            "num_kernel_terms": 128
        }
    }
]

Simulation timing requirements

The kernel is discretized at the solver time step, which constrains simulation_parameters:

  • cardiac_period / dt must equal z.size() in all cases.
  • Non-coupled configurations must set number_of_time_pts_per_cardiac_cycle = z.size() + 1.
  • 3D-coupled configurations must keep number_of_time_pts = 2 for the external interface step. If number_of_time_pts_per_cardiac_cycle is omitted, the cycle discretization is inferred from cardiac_period / dt.
  • steady_initial must be set to false. The steady initial condition is solved with a time step of cardiac_period / 10, which does not match the kernel discretization and has no meaningful interpretation for this boundary condition. Since steady_initial defaults to true, it must be set explicitly; otherwise the solver reports an error and exits.
