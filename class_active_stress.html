Detailed Description

Base class for chamber active stress models.

An ActiveStress owns the dynamics of a chamber's active stress . Subclasses may introduce additional internal variables and equations beyond ChamberSphere's fixed core state, and write directly into the same global SparseSystem that ChamberSphere writes into, using indices that are a fixed offset into ChamberSphere's own Block::global_var_ids and Block::global_eqn_ids arrays (which are passed down unchanged).

ChamberSphere::setup_dofs() always registers, in this order: internal variables radius, velo, stress, active_stress, volume, passive_stress, <extra_var_names()...> and equations momentum, spherical_stress, volume_change, acceleration, mass_conservation, pressure_equality, passive_stress, <this model's equations...>, so the offsets below are invariant across ActiveStress subclasses.
