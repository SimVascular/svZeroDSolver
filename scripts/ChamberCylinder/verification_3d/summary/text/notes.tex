\begin{itemize}
\item \textbf{svZeroD\_data time labels.} svMultiPhysics writes each row of
\texttt{results/svZeroD\_data} with the start time of its time step but the 0D state at
its end. Without a shift by $\Delta t$ the cavity pressure looked like it lagged by one
step ($3.6\cdot10^{-2}$ at nr = 4); with it, the error drops to $2\cdot10^{-3}$.
\item \textbf{Linear solvers.} fsils BiCGStab (the svMultiPhysics struct test default)
works for the eighth model up to nr = 8 for the full Holzapfel-Ogden wall, but stalls
for the full cylinder from nr = 2 on and, on the cluster, for the eighth model at nr = 8.
Trilinos GMRES with ML (algebraic multigrid) converges for these, but its quality falls
quickly with the number of MPI ranks (32 ranks: no residual reduction at all), so jobs
use 2--8 ranks. The coupled cases need GMRES, because fsils' BiCGStab leaves out the
coupled-boundary term of the tangent.
\item \textbf{PETSc.} The image also contains svMultiPhysics built with PETSc (MUMPS,
hypre). svMultiPhysics parses \texttt{<Configuration\_file>} but does not pass it on
to PETSc, and options passed through \texttt{PETSC\_OPTIONS} crashed (double free), so a
direct solver was not available.
\item \textbf{Rigid-body modes of the full cylinder.} Without support, GMRES stalls
(the discrete system is not exactly consistent). A weak epicardial spring works but is
ill-conditioned; two pinned radial lines disturb the wall locally; end dashpots give the
same results as the weak spring at the cost of neither (Section~\ref{sec:helical}).
\end{itemize}
